# RYUCHI — Site oficial

Versão aprovada: **Portais V4.1.1**.

Este repositório hospeda o site de fãs do Ryuchi. Abra o `index.html` no navegador para testar localmente. O HTML já inclui a capa de *Veterano 2* e a máscara de *Torii e Hutukara*.

## Publicar com GitHub Pages

1. Abra **Settings → Pages** deste repositório.
2. Em **Build and deployment**, selecione **Deploy from a branch**.
3. Em **Branch**, selecione **main** e **/(root)**, depois **Save**.
4. Após a implantação, o endereço padrão é https://ryusarto.github.io/site-ryuchi/

## Conectar ryuchi.com.br (opcional)

Quando quiser usar o domínio, configure **Custom domain** em Settings → Pages e ajuste os registros DNS no provedor do domínio conforme as instruções do GitHub. Ative **Enforce HTTPS** quando disponível. Não inclua um arquivo CNAME antes de configurar esse domínio.

**Importante:** algumas capas e links de streaming usam URLs externas ou buscas; revise os links oficiais antes de divulgar o site.
